## ⚡ Quick Tasks (5 minutes each)

### Export Your Data Right Now
```
1. Click "Export" button
2. Select dates (e.g., last 7 days)
3. Choose format (CSV or PDF)
4. Click "Export Data"
5. File downloads automatically
```
**Time**: 2 minutes | **Setup needed**: None ✅

### Connect a Wearable Device
```
1. Click "Devices" button
2. Paste your Fitbit/Oura/Garmin token
3. Click "Connect"
4. Click "Start Streaming"
5. Watch data update live
```
**Time**: 5 minutes | **Setup needed**: Device token (get from provider)

### Set Up Email Alerts
```
1. Click "Alerts" button
2. Enter your email address
3. Configure alert preferences
4. Click "Save Settings"
5. Click "Send Test Email"
```
**Time**: 5 minutes | **Setup needed**: Gmail app password (5 min extra)

### Watch Live Data
```
1. Connect a wearable device first
2. Click "Live Monitor"
3. Watch charts update in real-time
4. Receive instant alerts
```
**Time**: 2 minutes | **Setup needed**: Connected wearable

## 🔍 Troubleshooting

### Can't access http://localhost:3000?
→ Check if frontend is running: `npm start` in client folder

### API returning errors?
→ Restart backend: `npm start` in server folder

### Email not working?
→ Check .env file has EMAIL_USER and EMAIL_PASSWORD

### WebSocket not connecting?
→ Ensure backend is running on port 5000
