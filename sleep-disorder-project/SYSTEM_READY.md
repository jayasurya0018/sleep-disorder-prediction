## 🚀 Quick Start - Access Your Features

### 1. Open the Application
```
http://localhost:3000
```

### 2. Navigate to New Features
Look for these buttons in the top navbar:
- 📱 **Devices** - Connect wearable devices (Fitbit, Oura, Garmin)
- 📥 **Export** - Download sleep data (CSV/PDF)
- 📧 **Alerts** - Configure email notifications

### 3. Try These Features Right Now

#### Export Your Data (2 minutes)
1. Click **Export** in navbar
2. Select date range
3. Choose format (CSV or PDF)
4. Click "Export Data"
5. File downloads automatically

#### Set Up Email Alerts (5 minutes)
1. Click **Alerts** in navbar
2. Enter your email address
3. Choose alert types (severity, daily summary)
4. Click "Test Email" to verify
5. Save preferences

#### Connect a Wearable Device (optional)
1. Click **Devices** in navbar
2. Select device type (Fitbit/Oura/Garmin)
3. Enter API credentials from device provider
4. Click "Connect"
5. Start streaming real-time data

## 🔧 Optional Configuration

### Email Setup (5 minutes)
To enable email alerts, add to `server/.env`:
```env
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
```

### Wearable Device Tokens
Each device requires API credentials from:
- **Fitbit**: https://dev.fitbit.com
- **Oura Ring**: https://cloud.ouraring.com
- **Garmin**: https://developer.garmin.com
